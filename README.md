Описание:
<br>
В секцииях "Популярные товары" и "Акции и выгоднфе предложения" верстка выполнена для примера (без бэк-энда), с бэкэндом используется одна карточка товара, как шаблон, и повтаряется 5 раз (Это важно!). Данные для карточек должны браться из базы запросами.
