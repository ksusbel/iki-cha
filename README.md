# iki-cha
Магазин китайского чая IKI CHA
Посмотрите, как выглядит сайт: https://ksusbel.github.io/iki-cha/

Описание:
В секции "Популярные товары" верстка выполнена для примера (без бэк-энда), с бэкэндом используется одна карточка товара, как шаблон, и повтаряется 5 раз (Это важно!). Данные для карточек должны браться из базы запросами.
